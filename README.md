# FlySoloUltimate
Proyecto para la materia Desarrollo de Software

## Inicializacion del proyecto
### Backend
1) Abrir terminal.
2) Ir a la carpeta de backend (cd backend).
3) Instalar dependencias (npm/pnpm install).
4) Levantar backend (npm/pnpm dev).

### Frontend
1) Abrir nueva terminal.
2) Ir a la carpeta de frontend (cd frontend).
3) Instalar dependencias (npm/pnpm install).
4) Levantar frontend (npm/pnpm dev).
5) Utilizar el servidor a partir de la direccion que te da el frontend al ser levantado.
