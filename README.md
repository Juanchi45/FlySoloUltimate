# FlySoloUltimate
Proyecto para la materia Desarrollo de Software

## Como levantar el servidor
En una terminal por cada parte:
### Backend
1) Ir a la carpeta de backend (cd backend).
2) Instalar dependencias (npm/pnpm install).
3) Levantar backend (npm/pnpm dev).

### Frontend
1) Ir a la carpeta de frontend (cd frontend).
2) Instalar dependencias (npm/pnpm install).
3) Levantar frontend (npm/pnpm dev).
4) Utilizar la direccion que aparece en la terminal para utilizar las funcionalidades del servidor.
